# UI Screens Blueprint

> **Status:** Final
> **Scope:** Cross-cutting UI spec — screen-by-screen visual breakdown

## Global Drawer (Navigation)

- **Header:** User Identity Card — Avatar placeholder (circle) + Name + Age.
  - *Neuro-Logic:* Reinforces self-identity and age-awareness (combats time-blindness regarding life stages).
- **Navigation List:** Focus, Goals Management, Store, Fitness, Settings.
- **Footer:** App version + logout (secondary prominence).

---

## 1. Focus Module (display: "Now")

### Tab: Day Progress (Entry Screen)
- **Visual:** Pizza graphs (pie charts) for overall progress.
- **Cards:** One for goal progress, one for fitness progress.
- **Summary:** Today's events list (minimalist).

### Tab: Focus Timer
- Improved focus mode: zero-distraction UI with "Meaning Anchor".
- **Trajectory Summary:** Horizontal cards — daily wins, goal %, focus minutes.
- **Logistical Gate:** Unified pre-session ritual for resource/capacity check.

### Tab: Day Tasks
- Energy-filtered task selection.
- Calendar events with date, resources needed, place.

### Tab: Mental Dump
- Quick-entry text input for offloading thoughts.
- Daily reflection prompt UI.

---

## 2. Goals Module (display: "Mental Backlog")

### Tab: Goals Dashboard
- Pizza graphs for task completion per goal.

### Tab: Task Backlog
- Filterable list. **FAB:** Opens full-screen modal (better for complex input: resources, dates).

### Tab: Goals Backlog
- Filterable list. **FAB:** Full-screen modal for new goals + meaning linking.

### Tab: Meanings
- Interface to define intrinsic motivations ("The Why").
- Visual mapping of goals to meanings.

### Tab: Habits
- Recurring habit tracking interface.
- Streak calculation and visualization.

### Tab: Reflection Log
- Mood vs activity correlation.

---

## 3. Store Module (display: "Home Inventory")

### Tab: Resource Dashboard
- Categorized cards showing "Inventory Health".

### Tab: Management Store
- Category filter + FAB for adding resources.

### Tab: Resource Audit
- Log of additions/removals (transaction history).

---

## 4. Fitness Module (display: "Body Care")

### Tab: Fitness Dashboard
- Weekly progress cards + today's exercise list.

### Tab: Execution Screen
- **Circular Rest Timer:** Premium SVG/Reanimated visualization for neural recovery.
- **Tactile Controls:** Oversized +/- steppers for reps and weight logging.
- **Contextual Anchors:** "Last set" display for immediate performance baseline.
- **Rhythmic Pacer:** Visual pulses to help with motor planning and focus.

### Tab: Planning
- Task-tree view for planning body-part-specific sessions.

---

## User Settings

- **Profile:** Display name, age, avatar photo.
- **Preferences:** Color theme selection (light/dark/warm-dark).
- **Game Modes:** Progression styles (future, defaults to "Classic").
